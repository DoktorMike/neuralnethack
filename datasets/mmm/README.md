# Synthetic MMM dataset (boxed adstock benchmark)

Weekly marketing-mix data generated by `generate.cc` (seed 4711), the
same process as `examples/mmm_boxed.cc`: **50 insertion types = 10 media
channels x 5 messages** over 3 years, with known carryover regimes,
per-regime Hill saturation, and macro covariates. Built for exercising
the boxed adstock stage (`doc/spec-boxed-adstock.md`) against known
ground truth.

## Files

| File | Rows | Columns | Content |
|---|---|---|---|
| `mmm.trn.tab` | 124 | 654 | windowed training rows (first 124 weeks) |
| `mmm.tst.tab` | 32 | 654 | windowed holdout rows (last 32 weeks, chronological) |
| `mmm.raw.tab` | 168 | 55 | raw weekly series |

Whitespace-separated, no header, values printed with `%.6g`. Spends are
in currency units (weekly ~10,000-30,000 during flights, 0 otherwise) —
fit with `normalization = "maxabs"` (see doc/adstock.md); Z-centering or
raw scales both fail.

**Windowed layout** (654 columns), ready for `Adstock(50, 13, 3, ...)`:

- columns 1-650: lag windows, channel-major — channel c occupies columns
  `c*13+1 .. c*13+13` with lag 0 (current week) first, then older lags
- columns 651-653: covariates — season (annual sine), unemployment
  (slow random walk), linear trend
- column 654: sales (target)

**Raw layout** (55 columns): week index, 50 spends, season,
unemployment, trend, sales. Sales is 0 for the first 12 warmup weeks
(no complete lag window).

## Ground truth

Carryover regime is a property of the media; the message only scales
effectiveness. Media m belongs to regime `m / 2`; channel c is media
`c / 5`, message `c % 5`.

| Regime | Media | Carryover | Hill half-sat | Hill exponent |
|---|---|---|---|---|
| 0 | 0-1 | geometric, lambda 0.05 | 0.6 | 1 |
| 1 | 2-3 | geometric, lambda 0.30 | 0.8 | 1 |
| 2 | 4-5 | geometric, lambda 0.60 | 1.0 | 1 |
| 3 | 6-7 | geometric, lambda 0.85 | 1.2 | 2 (S-shaped) |
| 4 | 8-9 | delayed peak at week ~5: w_l ~ (l+1)^2 exp(-(l+1)/3) | 0.9 | 1 |

Kernels are normalized over the 13-week window. Message betas: 0.6, 0.8,
1.0, 1.2, 1.4 (message 0..4), media effect scale 0.8. Sales = 2.0 base
+ saturated media effects + 0.5*season - 0.8*unemployment + 1.0*trend
+ U(-0.03, 0.03) noise. Checksum: sum of the 156 sales values =
2909.493261.

## Expected model performance

A boxed adstock fit (K=5, Weibull + Hill, non-negative media betas,
entropy-penalty warmup schedule) lands around holdout R^2 0.84,
exact-box routing ~24/50, within-one-regime ~47/50 — see the honest
reading in `examples/mmm_boxed.cc`. Middle regimes (lambda 0.30 vs
0.60) are near the information limit of 156 weekly rows by design.

## Regenerating

```sh
g++ -std=c++23 -O2 -Ineuralnethack datasets/mmm/generate.cc \
    build/libneuralnethack.a -o /tmp/gen_mmm
cd datasets/mmm && /tmp/gen_mmm
```

## Config file

`config-mmm.toml` configures the whole boxed model — data columns,
linear head, `[adstock]` stage (K=5, Weibull + Hill, non-negative
betas) — through the standard config pipeline:

```cpp
TomlParser::parseFile("config-mmm.toml", config);
// load data with Parser::readDataFile per the [data.*] sections, then
auto trainer = Factory::createTrainer(config, trainData);
auto mlp = trainer->trainNew(trainData, std::cout);
```

Lands around holdout R^2 0.90 with the shipped settings (grouped max-abs input scaling, natural-unit target). The stock
`neuralnethack` binary is classification-oriented (it reports AUC), so
consume this config through the API as above. `entropy_penalty` stays 0
in the config on purpose — harden routing in a second phase via
`mlp->adstock()->entropyPenalty(0.01)` (see doc/adstock.md).
